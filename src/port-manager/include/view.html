状态含义与扫描范围

占用和预留均会排除在推荐之外。统计按端口 + 协议去重；表格按端口、协议和所有者合并。风险与占用、预留分开判断。“绑定重叠，需确认”表示不同进程的监听地址重叠，或 IPv4 / IPv6 绑定存在歧义；共享监听可能合法。“启动冲突风险”表示不同容器配置申请相同协议、端口和重叠地址，或容器配置与其他监听重叠，例如两个停止容器都配置 TCP 8080。风险不等同于已经启动失败。

推荐排除 1024 以下端口及系统动态范围，保守排除同协议的所有地址绑定。结果仅代表扫描时刻。独立 IP 容器和 VM 的内部端口不属于宿主机端口；未创建容器的模板不计入预留。
